# DNS-Resolver

## SETUP

- start by creating a virtual environment 
```bash
# WINDOWS:
py -m venv venv
venv\Scripts\activate

# LINUX:
python3 -m venv venv
source venv\bin\activate 
```

- install all the packages
```bash
pip install -r requiremnts.txt
```

- run the resolver
```bash
py main.py
```
